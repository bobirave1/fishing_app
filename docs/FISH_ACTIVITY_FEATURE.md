# Fish Activity Feed Feature

## Overview
Activity Feed сега показва **активността на рибите** (уловите) на конкретна локация.

## Как работи

### 1. Избор на локация
Потребителят избира локация от предварително зададен списък или въвежда своя:
- Варненско езеро
- Бургаско езеро
- Река Дунав
- Язовир Искър
- Язовир Батак
- Черно море
- Друга локация (custom input)

### 2. Търсене на улови
Системата търси публикации (posts) които съдържат:
- Името на локацията в заглавието
- Името на локацията в съдържанието
- Споменаване на видове риби

### 3. Показване на резултати
За всеки улов се показва:
- 🎣 Икона на рибата (според вида)
- Потребител и аватар
- Заглавие на публикацията
- Кратко описание
- Снимка (ако има)
- Време на публикуване

## API Endpoints

### GET /be/activity/feed.php?action=get_fish_activity&location=<location>
Връща списък с публикации (улови) на дадена локация.

**Response:**
```json
{
  "success": true,
  "activities": [
    {
      "id": 1,
      "user_id": 5,
      "username": "fisherman",
      "avatar_url": "path/to/avatar.jpg",
      "title": "Уловен голям шаран на Варненското езеро",
      "content": "12кг шаран с царевица...",
      "image": "path/to/image.jpg",
      "created_at": "2026-01-25 14:30:00"
    }
  ],
  "location": "varna_lake"
}
```
