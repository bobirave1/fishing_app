# Автоматична Настройка на База Данни

## За Нов Компютър

Когато клонираш проекта на нов компютър:

### Метод 1: Двоен клик (НАЙ-ЛЕСНО!) 🚀
1. Стартирай XAMPP (Apache и MySQL)
2. **Двоен клик на `setup.bat`** - Готово!
3. Автоматично ще се изпълни всичко

### Метод 2: Автоматична настройка през браузър
1. Стартирай XAMPP (Apache и MySQL)
2. Отвори в браузър: `http://localhost/fishing_app/setup.php`
3. Скриптът автоматично ще:
   - Създаде базата данни `fishing_app`
   - Импортира структурата от `fishing_app.sql`
   - Изпълни всички миграции от папката `migrations/`

### Метод 3: Чрез команден ред
```bash
cd c:\xampp\htdocs\fishing_app
php setup.php
```

## Как работи?

- **Първи път:** Автоматично създава и импортира всичко
- **Вече има база:** Пропуска импортирането и показва какво има
- **config/database.php:** Автоматично пренасочва към setup ако базата липсва

## Експортиране на промени

Преди да правиш commit с нови промени в базата:

### Опция 1: Експорт на цялата база
```bash
# Отвори phpMyAdmin
# Export → fishing_app → SQL формат
# Запази като fishing_app.sql
```

### Опция 2: Само нови промени (препоръчително)
Създай нов файл в `migrations/` с промените:
```sql
-- migrations/add_new_feature.sql
ALTER TABLE users ADD COLUMN new_field VARCHAR(255);
```

## Структура

```
fishing_app/
├── setup.php              ← Автоматичен setup скрипт
├── fishing_app.sql        ← Основна база данни
├── migrations/            ← Допълнителни промени
│   └── add_notifications.sql
└── config/
    └── database.php       ← Авто проверка за база
```

## Важно!

✅ Винаги стартирай `setup.php` на нов компютър  
✅ Не променяй ръчно `config/database.php` без нужда  
✅ Създавай миграции за нови промени в структурата
